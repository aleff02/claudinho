# Ata — gravador de reuniões (Android)

App nativo (Kotlin). Grava em serviço de primeiro plano e continua com a tela bloqueada.
Marcas (Importante, Decisão, Tarefa, Dúvida), anotações com horário, busca, ata para compartilhar.

Compilar: Android Studio > Build > Build APK(s), ou `./gradlew assembleDebug`.
